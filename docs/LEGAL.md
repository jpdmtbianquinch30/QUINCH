# Conformité et cadre légal QUINCH

> Ce document est une checklist produit/technique. Il ne remplace pas un conseil juridique professionnel.

## Statut actuel

QUINCH est actuellement un projet en cours et n'est pas présenté dans le dépôt comme une société déjà constituée.

Avant la commercialisation publique, confirmer le statut juridique, fiscal et les obligations applicables au Sénégal.

## Pages publiques à préparer

- Mentions légales ;
- Conditions générales d'utilisation ;
- Politique de confidentialité ;
- Politique cookies si applicable ;
- règles de publication/modération ;
- contact/support ;
- suppression de compte.

## Données personnelles

Documenter :

- identité/contact ;
- compte ;
- profil ;
- messages ;
- médias ;
- journaux de sécurité ;
- données de paiement ;
- cookies/analytics ;
- finalité ;
- durée de conservation ;
- droits utilisateur ;
- sous-traitants ;
- lieu d'hébergement.

## Contenu utilisateur

Prévoir :

- signalement ;
- modération ;
- retrait ;
- appel/contestation ;
- sanctions ;
- règles contre fraude/abus.

## Paiements

Les CGU doivent clairement expliquer que QUINCH facture ses propres fonctionnalités et ne gère pas le règlement des ventes entre utilisateurs, si ce modèle est maintenu.

## Hébergement

Documenter l'hébergeur et les sous-traitants réels utilisés au moment de la mise en ligne.
