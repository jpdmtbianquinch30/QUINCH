Bienvenue sur QUINCH

QUINCH est une place de marché sénégalaise pour acheter, vendre et proposer des produits et des services, avec des vidéos, une messagerie intégrée et un système de confiance. Ce guide répond aux questions les plus courantes.

1. Démarrer

  1. Créer un compte avec votre numéro (+221…) et un mot de passe.
  2. Confirmer le code SMS reçu à 6 chiffres.
  3. Recevoir le message de bienvenue de l'équipe QUINCH.
  4. Compléter le profil (photo, ville, description) pour atteindre 80 % de confiance.

Pas de SMS ? Attendez une minute avant de redemander un code. Le nombre d'envois est limité par heure pour votre sécurité.

2. Score de confiance

Le score (en %) rassure acheteurs et vendeurs. À partir de 80 %, votre profil inspire pleinement confiance.

Allez dans Profil → Modifier pour compléter les champs.

3. Explorer et Feed

  • Feed : annonces récentes, filtrables par catégorie, produit ou service, avec recherche.
  • Explorer : toutes les annonces, avec ou sans vidéo. Les comptes Premium sont mis en avant.
  • Vidéos : défilement vertical façon réseau social. Touchez une vidéo pour l'ouvrir ; glissez pour passer à la suivante.
  • Favoris : le signet enregistre une annonce ; le cœur indique que vous l'aimez.

5. Vidéos

  • Premium publication de vidéo incluse.
  • Gratuit vous pouvez publier une vidéo en payant 150 F de frais de publication : la vidéo apparaît alors dans le feed vidéo et gagne en visibilité.
  • Les annonces sans vidéo restent visibles dans Explorer.
  • Formats conseillés : MP4, vertical, quelques dizaines de secondes.

6. Messages

  • L'onglet Tous (par défaut) affiche toutes vos conversations ; Mes amis n'affiche que les abonnements mutuels.
  • Vous pouvez envoyer texte, images, fichiers et messages vocaux.
  • Une notification de message ouvre directement la bonne conversation.
Conseil sécurité : ne communiquez jamais votre mot de passe ou un code SMS. QUINCH ne vous les demandera jamais.

7. Premium

  • 11 photos par annonce, vidéos incluses, mise en avant dans Explorer et le feed.
  • Accès au Classement des vendeurs.
  • Paiement via Wave depuis Premium.

Si votre paiement est débité mais le Premium n'apparaît pas, contactez le support avec votre numéro.

9. Classement

Le classement met en avant les meilleurs profils selon avis, activité et confiance. Vous pouvez choisir d'y participer ou non.

10. Notifications

  • La cloche affiche le nombre de non lues, dans le feed comme dans le menu.
  • Chaque notification mène au bon endroit : message → conversation, abonnement → profil, mention → annonce.
  • Les messages de l'équipe QUINCH apparaissent aussi en haut du feed jusqu'à ce que vous les fermiez.

11. Sécurité

  • Rencontrez-vous dans un lieu public ; vérifiez l'article avant de payer.
  • Méfiez-vous des prix trop bas et des demandes de paiement à l'avance hors QUINCH.
  • Utilisez un mot de passe unique et ne le partagez pas.
  • Vous pouvez bloquer un utilisateur depuis son profil.

12. Signaler

Le bouton Signaler est disponible sur une annonce, une vidéo et un profil. Choisissez le motif ; notre équipe traite chaque signalement depuis l'administration. Un abus répété de signalements peut être sanctionné.

13. Mon compte

  • Changer de numéro : Profil → Modifier → Téléphone → Modifier. Mot de passe, puis code SMS sur le nouveau numéro.
  • Mode clair / sombre : Réglages.
  • Exporter mes données et supprimer mon compte : Réglages.

14. Questions fréquentes

Ma vidéo n'apparaît pas dans le feed.

Elle peut être en vérification, ou les frais de publication de 150 F (compte gratuit) ne sont pas réglés.

Mon annonce a disparu.

Elle a pu être masquée par la modération ou désactivée par vous. Consultez vos notifications.

Je n'arrive pas à me connecter.

Après plusieurs essais échoués, la connexion est bloquée quelques minutes. Réessayez plus tard ou réinitialisez votre mot de passe.

Comment atteindre 80 % de confiance ?

Complétez votre profil, vérifiez votre numéro et obtenez de bons avis.

15. Besoin d'aide ?

Ouvrez un ticket depuis Réglages → Aide ou répondez au message de l'équipe QUINCH reçu dans vos notifications.
